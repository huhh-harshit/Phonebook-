# Python Phonebook Application

A simple command-line Phonebook Application built using Python. It allows users to manage contacts easily.

## Features
- Add a new contact
- Search for a contact
- Delete a contact
- Display all contacts
- Exit the application

## Technologies Used
- Python 3
- Dictionary
- Functions
- While Loop
- If-Else Statements

## How to Run

1. Clone this repository.
2. Open the project folder in your terminal.
3. Run the following command:

```bash
python phonebook.py
```

## Storage
Contacts are stored in a Python dictionary. Data is temporary and will be lost when the program exits.
